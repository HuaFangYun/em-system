# EmSys.Ui.Core 0.1.0-alpha.11

Date: 2026-10-13
Previous: 0.1.0-alpha.10

## Summary
Adds the client side of the new log engine: a local log outbox that is sent to the server while a user is signed in, and service proxies for ILogServices and IAuditServices.

## New features

- `ClientLogProvider` (`Em.Ui.Core.Logging`): an `ILoggerProvider` that writes log events to a local outbox folder (200 MB limit, oldest segments dropped and counted). Events keep the user of the moment they were written.
- `ClientLogShipper`: sends outbox batches with `PostMeta_LogIngest` while a user is signed in and before sign-out; batch ids make resends harmless.
- `ClientLogFolder` and `ClientLogOptions` configure the outbox folder, application name and version.
- `LogClientService` (`ILogServices`) and `AuditClientService` (`IAuditServices`) proxies.

## Usage notes

- New dependency: `Microsoft.Extensions.Logging` 10.0.10.
- `EmSys.Ui.Wpf.Core` and `EmSys.Ui.Maui.Core` wire these up automatically. Guide: `doc/engine/engine-log.md`.
