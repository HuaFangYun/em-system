# EmSys.Ui.Maui.Core 0.1.0-alpha.11

Date: 2026-10-13
Previous: 0.1.0-alpha.10

## Summary
Connects MAUI clients to the new log engine: the application logs to a local outbox under the app data directory and sends it to the server while a user is signed in.

## New features

- `EmApp.LoggerFactory`, `EmApp.LogFolder` and `EmApp.SendLogsAsync()`. The outbox is `FileSystem.AppDataDirectory/Logs/outbox`; shipping starts when a user signs in, and the remaining log is sent before sign-out (at most five seconds, never blocking the user).
- `ILoggerFactory`, `ILogger<T>`, `ILogServices` and `IAuditServices` are registered in the service provider.
- Unhandled exceptions and unobserved task exceptions are logged as errors.

## Upgrade notes

- Logs reach the server only when it runs `AddLogServer()` (`EmSys.Api.Core` 0.1.0-alpha.11). Guide: `doc/engine/engine-log.md`.
