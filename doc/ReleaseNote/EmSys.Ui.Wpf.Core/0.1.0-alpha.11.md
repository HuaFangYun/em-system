# EmSys.Ui.Wpf.Core 0.1.0-alpha.11

Date: 2026-10-13
Previous: 0.1.0-alpha.10

## Summary
Adds the Log Manager screen for the new log engine, an Activity tab in the User Editor, and a client log that is sent to the server while a user is signed in. EmTabStrip no longer shows close buttons when it has no CloseCommand.

## New features

- **Log Manager** (navigation `EmApp.LogManagerNavigationName` = `admin.logmanager`, claim `Log Manager Access`), listed in the Tools menu with the other managers. It has tabs for the server and client log, grouped errors with triage, audit entries, and security events (sign-in, passwords, failed sign-ins); each tab follows its own read claim. **Settings** has **Database** (log stores: Test, Prepare, Save) and **Retention** (rules with Preview), behind `Log Manager Settings`.
- **Activity** tab in the User Editor for stored users: the account's sign-in, password and user changes, newest first, with Load more.
- Client log: `EmApp.LoggerFactory`, `EmApp.LogFolder` and `EmApp.SendLogsAsync()`. The outbox is `%LocalAppData%\<ApplicationName>\Logs\outbox`; shipping starts when a user signs in, and the remaining log is sent before sign-out. Unhandled exceptions are logged as errors. `ILoggerFactory`, `ILogger<T>`, `ILogServices` and `IAuditServices` are registered in the service provider.
- Tools menu item **Open log folder** opens the local log outbox.

## Fixes

- `EmTabStrip`: a strip without `CloseCommand` has fixed tabs and no longer shows a close button on them.

## Upgrade notes

- Log Manager and the Activity tab need a server with `AddLogServer()` enabled (`EmSys.Api.Core` 0.1.0-alpha.11); without it the navigation is hidden because the server does not declare its claim.
- Guide: `doc/engine/engine-log.md`.
