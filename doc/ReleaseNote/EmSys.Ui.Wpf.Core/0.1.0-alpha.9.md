# EmSys.Ui.Wpf.Core 0.1.0-alpha.9

Date: 2026-10-11
Previous: 0.1.0-alpha.8

## Summary
Adds EmTabStrip, a shared tab strip control for switching panels within one screen, together with shared styles for a tab strip menu button and cascading menus. The reload button on a tab of the multi-tab main window now follows the navigation's IsReloadVisible switch, like the single-page toolbar.

## New features

- **`EmTabStrip`** (`Em.Ui.Wpf.Controls`): a horizontal tab strip with the same 40-pixel tabs, selection underline and scroll buttons as the main window. It derives from `ListBox`, so `ItemsSource` and `SelectedItem` work as usual.
  - `TitlePath` (default `Title`) names the item property shown as the tab text and tooltip, and follows property change notifications.
  - `CloseCommand` runs from the close button and from a middle click, with the item as parameter.
  - `CanReorder` (default `true`) lets the user drag tabs to a new position. An `ObservableCollection<T>` source is moved with `Move`; other writable `IList` sources with remove/insert. For a read-only source the control raises `ItemMoved` (`Item`, `OldIndex`, `NewIndex`) and the owner performs the move. `MoveItem` and the static `TryMove(IList, int, int)` expose the same operation to code.
  - `MinItemWidth` (default 130) is how far long tabs shrink before the strip scrolls.
  - `LeadingContent` and `LeadingContentTemplate` place optional content, such as a menu button, to the left of the tabs; when null no space is reserved.
  - The control has no detach, reload, context menu or cross-window behavior; the main window keeps its own tab strip.
- Shared menu styles in `MaterialDesign.xaml`: `tabStripMenuButtonStyle` for a menu toggle button in a tab strip, `cascadeContextMenuStyle` and `cascadeMenuItemStyle` for themed context menus with nested submenus, checked items, separators and disabled rows, and `menuTitleSubtitleTemplate` for two-line menu rows with a `Title` and an optional `Subtitle`. Apply `cascadeMenuItemStyle` to submenu items as well.
- In the multi-tab main window (`TabbedMainWindow`), a navigation registered with `IsReloadVisible = false` no longer shows the reload button on its tab, and the **Reload** item is removed from the tab's context menu. The default stays `true`, so existing navigations are unchanged. Reloading from code (`INavigationEntry.Reload()`) still works.
