# EmSys.Ui.Wpf.Core 0.1.0-alpha.12

Date: 2026-10-15
Previous: 0.1.0-alpha.11

## Summary
Object Storage Manager and the bucket editor show managed buckets, which are declared by an application module through EmSys.Api.Core. A managed bucket is marked with its owner and description, its contents are read-only, its policy is locked, and an administrator can release one that is no longer declared.

## New features

- Bucket lists show a MANAGED chip with the owner ("Managed by ...") and a NOT DECLARED chip for a managed bucket the running API no longer declares.
- The bucket editor shows the declared description read-only and keeps the policy of a managed bucket locked.
- The object browser of a managed bucket is read-only: upload, delete, restore and version purge are not available and dropped files are refused; browsing, versions and download stay available.
- **More › Release managed bucket** turns an undeclared managed bucket into an ordinary bucket after confirmation.
- In the policy editor, the access of a managed policy cannot be changed.
- `ObjectStorageService` implements the new `PostMeta_StoreBucketRelease` action of `EmSys.Libs` 0.1.0-alpha.12.
