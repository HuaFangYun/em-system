# EmSys.Ui.Wpf.Core 0.1.0-alpha.10

Date: 2026-10-11
Previous: 0.1.0-alpha.9

## Summary
Adds the Object Storage Manager screen and a bucket editor for the new object storage engine, with a home screen card that shows logical and physical storage size, and a NumericInput behavior for number-only text boxes. Date pickers and calendars now stay readable in dark mode.

## New features

- **Object Storage Manager** (navigation `admin.objectstorage`, Administrative Tools, claim `Object Storage Manager Access`), registered by the core and listed in the Tools menu with the other managers:
  - **Buckets**: bucket table with policy, object count, logical size, quota and access. Double-click or **Open in tab** opens the bucket editor; **Browse** opens the in-place object browser with breadcrumb path, pseudo-folders from `/`, upload from the toolbar or by dragging files, download, delete, **Load more** for long listings, and a **Versions** side sheet to restore, download or permanently delete a version.
  - **Volumes**: volume table with copies, size, missing copies and a live folder check; editor with **Check**.
  - **Policies**: replicas, retention, quotas (MB), access and an ordered volume list. Every field explains its rule in a tooltip, also when the editor is read-only, and the optional number fields accept digits only (empty means no limit).
  - **Maintenance**: status counters, garbage collection (**Review**, then **Run**), retention and repair runs, and the running task list.
- **Bucket editor** (navigation `EmApp.ObjectStorageBucketNavigationName` = `admin.objectstorage.bucket`, same claim): one bucket's settings above its object browser and version sheet, on its own tab. Any screen can open it with `StoreBucketNavigationPayload.Open(bucketName, prefix)` (prefix optional, e.g. `"2026/"`) or create a bucket with `StoreBucketNavigationPayload.New()`.
- `NumericInput` (`Em.Ui.Wpf.Shared`): attached property `NumericInput.Kind` (`None`, `Integer`, `Decimal`) that refuses typed and pasted characters other than digits (and one culture decimal separator for `Decimal`) on an ordinary `TextBox`. The text may stay empty, so it suits optional limits; use `NumericBox` when a value is always required.
- Home screen card for the Object Storage Manager showing logical versus physical size and the number of volumes with problems, with its own refresh button.
- `IObjectStorageServices` client (`ObjectStorageService`) registered in the service provider.

## Fixes

- Dark mode: text in `DatePicker` popups (day, month and year buttons) and in `inlineDatePickerStyle` now uses the theme foreground instead of a dark default, so it is readable on a dark background. Selection and disabled states are unchanged.

## Upgrade notes

- The screen needs a server with `AddObjectStorage()` enabled (`EmSys.Api.Core` 0.1.0-alpha.10); without it the navigation is hidden because the server does not declare its claim.
- Guide: `doc/engine/engine-object-storage.md`.
