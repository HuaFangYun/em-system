# EmSys.Libs 0.1.0-alpha.10

Date: 2026-10-11
Previous: 0.1.0-alpha.9

## Summary
Adds the contracts for the new object storage engine: IObjectStorageServices for managing volumes, policies, buckets, objects and versions and for running maintenance, together with their request and result models.

## New features

- `IObjectStorageServices` (module `Administrative Tools`) with the claims `Object Storage Manager Access` (browse, upload, download, delete, restore) and `Object Storage Settings Manage` (volumes, policies, buckets, permanent version delete and maintenance runs).
  - Status: `GetMeta_StoreStatus`.
  - Volumes: `GetMeta_StoreVolumes`, `PostGetMeta_StoreVolumeValidate`, `PostGetMeta_StoreVolumeSave`, `PostMeta_StoreVolumeDelete`.
  - Policies: `GetMeta_StorePolicies`, `PostGetMeta_StorePolicySave`, `PostMeta_StorePolicyDelete`.
  - Buckets: `GetMeta_StoreBuckets`, `PostGetMeta_StoreBucketSave`, `PostMeta_StoreBucketDelete`.
  - Objects: `GetMeta_StoreObjects` (prefix, delimiter, continuation, limit), `GetMeta_StoreObject`, `PostGetMeta_StoreObjectUpload` (streamed), `GetMeta_StoreObjectDownload` (streamed), `PostMeta_StoreObjectDelete`.
  - Versions: `GetMeta_StoreObjectVersions`, `PostGetMeta_StoreObjectRestore`, `PostMeta_StoreObjectVersionPurge`.
  - Maintenance: `GetMeta_StoreGcReview`, `PostGetMeta_StoreGcRun`, `PostGetMeta_StoreRetentionRun`, `PostGetMeta_StoreRepairRun`, `GetMeta_StoreTasks`.
- Models: `StoreStatus`, `StoreVolumeInfo`, `StoreVolumeSave`, `StoreVolumeValidation`, `StorePolicyInfo`, `StorePolicySave`, `StoreBucketInfo`, `StoreBucketSave`, `StoreObjectInfo`, `StoreObjectListing`, `StoreObjectVersionInfo`, `StoreUploadRequest`, `StoreGcReview` and `StoreGcBlob`, plus the enums `StoreVolumeType`, `StoreVolumeState`, `StorePolicyState`, `StoreAccess`, `StoreBucketState`, `StoreBlobState` and `StoreBlobCopyState`.
- ORM models for the object storage store, used by `EmSys.Api.Core`.

## Usage notes

- The engine itself and the in-process `IObjectStore` API for modules are in `EmSys.Api.Core`; the manager screen is in `EmSys.Ui.Wpf.Core`. Guide: `doc/engine/engine-object-storage.md`.
