# EmSys.Libs 0.1.0-alpha.11

Date: 2026-10-13
Previous: 0.1.0-alpha.10

## Summary
Adds the contracts for the new log engine: ILogServices for Log Manager (telemetry, grouped errors, audit search, log stores and retention) and client log ingest, and IAuditServices for module screens that show the activity history of their own documents.

## New features

- `ILogServices` (module `Defaults.LogModuleName` = `core.log`) with the claims `Log Manager Access`, `Log Telemetry Read`, `Log Audit Read`, `Log Security Read` and `Log Manager Settings`.
  - Client telemetry: `PostMeta_LogIngest`.
  - Telemetry and errors: `GetMeta_LogSummary`, `GetMeta_LogEvents`, `GetMeta_LogErrors`, `GetMeta_LogErrorDetail`, `PostMeta_LogErrorState`.
  - Audit and security: `GetMeta_LogAudit`, `GetMeta_LogSignInFailures`, `GetMeta_AuditCatalog`.
  - Log stores: `GetMeta_LogStores`, `PostGetMeta_LogStoreTest`, `PostGetMeta_LogStorePrepare`, `PostGetMeta_LogStoreSave`.
  - Retention: `GetMeta_LogRetention`, `PostGetMeta_LogRetentionPreview`, `PostGetMeta_LogRetentionSave`.
- `IAuditServices` (module `Defaults.AuditModuleName` = `core.audit`): `GetMeta_AuditActivity_ByDoc`, `_ByDocNo`, `_ByType`, `_ByTarget`, `_Since`, and `PostMeta_AuditEntry` for events reported by clients. Read rights come from each audit group's own read rule, not from the Log Manager claims.
- Models for log events, error groups, ingest batches, audit activity pages (newest first, opaque `NextCursor`), the audit catalog, log store settings and retention rules.

## Usage notes

- The engine itself (`AddLogServer()`, `AddAudit(...)`, `IAuditWriter`) is in `EmSys.Api.Core`; the client log and service proxies are in `EmSys.Ui.Core`; Log Manager is in `EmSys.Ui.Wpf.Core`. Guide: `doc/engine/engine-log.md`.
