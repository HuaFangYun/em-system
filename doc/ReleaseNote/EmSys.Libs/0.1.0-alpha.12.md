# EmSys.Libs 0.1.0-alpha.12

Date: 2026-10-15
Previous: 0.1.0-alpha.11

## Summary
Extends the object storage contract for managed buckets, which are declared by an application module through EmSys.Api.Core. Bucket and policy information now say whether a bucket is managed, by whom and why, and a new action releases a managed bucket that is no longer declared.

## Breaking changes

- `IObjectStorageServices` has a new action, `PostMeta_StoreBucketRelease(string bucketId)`. Classes that implement the interface must add it; callers are not affected.
- `StoreBucketInfo` and `StorePolicyInfo` gained optional positional parameters at the end. Code that calls their constructors compiles unchanged, but must be recompiled against this version; positional deconstruction now has the extra elements.

## New features

- `StoreBucketInfo.Owner`, `Description` and `IsDeclared`, with `IsManaged` (the bucket is owned by an application) and `IsUndeclared` (managed, but the running API no longer declares it).
- `StorePolicyInfo.ManagedBucket` names the managed bucket a policy belongs to, with `IsManaged`.
- `IObjectStorageServices.PostMeta_StoreBucketRelease` turns an undeclared managed bucket into an ordinary bucket and keeps its contents; 409 for a bucket that is not managed or is still declared.
- The interface documentation lists which management actions answer 409 for a managed bucket (object upload, delete, restore and version purge; policy change, access change and deletion).
